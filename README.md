# Be The Agent

축구 선수 에이전트가 되어 주 단위로 시간을 보내는 웹 텍스트 게임입니다. HTML, CSS, JavaScript 파일 3개로만 만들었고 외부 라이브러리 없이 오프라인에서도 동작합니다.

## 실행

- 폰: GitHub Pages 주소를 엽니다. 홈 화면에 추가해 두면 저장이 더 오래 유지됩니다.
- PC: `index.html`을 브라우저로 엽니다.

## 지금 할 수 있는 것 (1단계)

- 소속 선수 5명 관리 화면: 능력, 잠재력, 폼, 몸값, 계약 만료 시점
- **다음 주 ▶**로 1주씩 진행. 52주가 지나면 시즌이 바뀌고 나이·몸값이 갱신됩니다
- 가상 세계 58개국 123개 리그, 구단 2,002개, 선수 48,048명 탐색
- 자동 저장, 저장 파일 내보내기·불러오기, 새 게임

영입과 협상은 다음 단계에서 만듭니다.

## 저장

진행 상황은 브라우저의 localStorage에 자동으로 저장됩니다. iPhone Safari는 7일 동안 사이트를 쓰지 않으면 저장을 지울 수 있으니 **기록 → 파일로 내보내기**로 백업해 두세요.

## 개발

작업 규칙, 단계 계획, 수식, 세이브 형식은 [AGENTS.md](AGENTS.md)에 있습니다. 첫 프로토타입은 `prototype-v0` 태그에 남아 있습니다.

모든 리그·구단·선수는 가상입니다. 실존 단체나 인물과 관계없습니다.
