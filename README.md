# Be The Agent

축구 선수 에이전트가 되어 주 단위로 시간을 보내는 웹 텍스트 게임입니다. HTML, CSS, JavaScript 파일 3개와 글꼴(Pretendard)로만 만들었고 외부 라이브러리 없이 오프라인에서도 동작합니다. 한국어와 영어로 할 수 있습니다.

> **English:** A text-based football agent game for the browser. Sign unknown players, look after them week by week, negotiate contracts and transfers, and build your agency. Switch between 한국어 and English under **Log → Language**. Everything runs offline from three files.

## 실행

- 폰: GitHub Pages 주소를 엽니다. 홈 화면에 추가해 두면 저장이 더 오래 유지됩니다.
- PC: `index.html`을 브라우저로 엽니다.

## 지금 할 수 있는 것 (11단계)

- **영어 버전:** 기록 탭 아래 "언어 · Language"에서 한국어/English를 바꿉니다(처음에는 브라우저 언어를 따름). 선수·구단 이름, 뉴스, 인연·기억·이야기 앨범이 바로 바뀝니다. 소식은 종류마다 상황 글 3가지와 선수의 말 3~5가지 중 하나가 나와서, 같은 일이라도 선수마다 다르게 말합니다
- **혼자 시작:** 회사 없이 아는 사이인 무명 선수 2명의 대리인으로 시작합니다(고향 후배, 대학 은사의 제자 등). 혼자서는 3명까지, 한 주에 AP 1입니다
- **에이전시 세우기:** 평판·자금·수수료 조건을 채우면 에이전시 탭에서 회사를 세웁니다. 함께해 온 선수들이 따라오고, 한도 6명·AP 2·법인 투자가 열립니다
- **선수와의 유대:** 선수마다 유대(서먹함 → 믿음 → 끈끈함 → 가족 같음)가 쌓입니다. 소식에 어떻게 답하느냐에 따라 오르내리고(버튼에 "유대 +5"처럼 표시), 선수는 최근에 있었던 일을 기억합니다. 유대가 깊으면 다른 에이전시가 와도 남고, 이적을 권하면 따라옵니다
- **관계 이야기:** 유대가 깊어지고 함께한 시간이 쌓이면 선수마다 이야기가 찾아옵니다(밤 11시의 전화, 가족 결혼식, 후배 소개, 인터뷰의 고마움). 이야기가 오면 다음 주 직후 화면 아래에서 장면이 올라와 선수의 말을 크게 보여 주고, 선수 상세의 이야기 앨범에 고른 답이 남습니다(아직 안 열린 칸에는 필요한 유대가 보입니다). 오래 함께한 선수가 은퇴하면 은퇴식이 열리고, 아주 가까웠던 선수는 고향에서 스카우트로 일해 줍니다
- **이적 시장:** 계약 중인 선수의 이적 제안은 여름(47주 ~ 다음 시즌 6주)·겨울(22~26주) 이적 기간에만 옵니다. 마감일에는 막판 제안이 몰리고 그 주 안에 답해야 합니다. 지금 구단이 안 맞는 선수는 이적 기간에 새 구단을 찾아 달라고 털어놓고, 알아봐 주면 마감까지 제안이 더 자주 옵니다. 무소속 선수는 언제든 계약할 수 있습니다
- **세계 뉴스:** 이적 기간이 열리면 구단들이 어느 포지션이 부족한지 알리고, 기간 동안 실제로 선수를 데려옵니다("잉글랜드 1부 런던 크라운이 수비수 보강에 나섰습니다", "…를 이적료 $480만에 영입했습니다"). 내 선수가 맞는 보강에는 1 AP로 추천할 수 있고, 추천하면 그 구단에서 제안이 올 가능성이 높아집니다. 내 선수 이적과 첫 국가대표 발탁도 뉴스에 실립니다
- 소속 선수 관리(회사를 세우면 6명, 평판이 오르면 7명, 사무실 확장으로 +1명): 능력, 잠재력, 폼, 몸값, 주급, 계약 만료 시점
- 선수별 시즌 기록: 리그·국내 컵·대륙 대회·국가대표 경기, 골, 도움, 평점, 지난 시즌 기록
- 선수 성향과 원하는 조건(주급, 계약 기간, 출전 시간, 큰 무대, 국내·해외, 꿈의 구단)을 ✓/✗로 확인
- **다음 주 ▶**(영어 **Next ▶**)로 1주씩 진행. 매주 수수료(주급의 8%)가 들어오고 운영비와 투자 유지비가 나갑니다
- 52주가 지나면 시즌이 바뀌고 나이·능력·몸값이 갱신됩니다. 어린 선수는 잠재력까지 자라고 30대는 내려갑니다
- 가상 세계 58개국 123개 리그, 구단 2,002개, 선수 48,048명 탐색
- **유망주 찾기:** 다른 구단 23세 이하 선수의 잠재력은 "70~86"처럼 범위로만 보입니다. 스카우트(1 AP)를 보낼수록 좁아지고, 영입하면 정확히 드러납니다. 리그 탭 맨 위에서 나이·포지션으로 찾고 관심 목록(20명)에 넣어 둘 수 있습니다
- 선수를 눌러 영입 제안(혼자일 때 주 1 AP, 회사를 세우면 주 2 AP), 계약 해지
- 소속 선수 면담으로 만족도 관리. 만족이 너무 떨어지면 선수가 떠납니다
- 재계약 협상(주급 3단계 × 기간 2가지), 이적 제안 수락(선수 동의 확률)·더 요구·거절, 이적 수수료
- 매주 소식 카드: 부상, SNS 논란, 광고 제안, 다른 에이전시 접근 등에 선택지로 답하기
- **에이전시 탭:** 번 돈을 쓰는 곳
  - 법인 투자: 변호사(재계약 주급 +), 스카우트망(영입 확률 +, 더 좋은 유망주 추천), 피지컬 코치(성장 +, 30대 하락 줄임), 사무실 확장(소속 한도 +1). 도입비와 주간 유지비가 있고 단계를 낮출 수 있습니다
  - 법인 자금과 개인 자금이 나뉩니다. 배당(법인 → 개인)은 세금 15%, 개인 자금을 법인에 넣을 때는 세금이 없습니다
  - 개인 아이템 6종(정장부터 요트까지): 개인 자금으로 사고, 살 때 평판이 오릅니다
- 자금 마이너스가 8주 이어지면 파산
- 자동 저장, 저장 파일 내보내기·불러오기, 새 게임

앞으로는 다른 게임에서 검증된 요소를 하나씩 가져와 넣습니다. 후보는 [AGENTS.md](AGENTS.md) 0장에 있습니다.

밸런스는 `node tools/sim.js --games 1000 --all`로 수천 판을 돌려 맞춥니다 (개발용, 게임에는 포함되지 않음).

## 저장

진행 상황은 브라우저의 localStorage에 자동으로 저장됩니다. iPhone Safari는 7일 동안 사이트를 쓰지 않으면 저장을 지울 수 있으니 **기록 → 파일로 내보내기**로 백업해 두세요.
